# Fintech SQL Project

This project focuses on analyzing a financial technology dataset using SQL. It includes various queries to extract insights regarding customer transactions, fraudulent activities, and regional performance.

## Key Insights Explored:
* **Customer Analysis:** Total transaction amounts and high-frequency users.
* **Fraud Detection:** Identifying and totaling fraudulent transactions.
* **Operational Metrics:** Average transactions by account type and processing fees by currency.
* **Regional Data:** Analysis of transaction volumes across different regions.

## How to use:
The SQL queries can be found in the `fintech-sql-project` file.
